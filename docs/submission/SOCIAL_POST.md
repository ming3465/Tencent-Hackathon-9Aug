## 0. THE HONESTY PROBLEM — read this first

### The situation

Two of the four required hashtags name tools we did not use.

| Tag | What is actually true, today |
|---|---|
| `#TencentCloudHackathon` | **True usage.** We are entered in it. Safe to use in any sentence. |
| `#CodeBuddy` | **Partial, and it is documented.** CodeBuddy CLI 2.127.0 authored the initial Phase 1 codebase (10 files, incl. the match engine that still ships). That run overran its 50-turn limit and shipped 2 type errors, 3 failing tests, an unused dep, 4 audit findings and a timer race. All were caught by our verification gate and fixed. The follow-up correction request returned `429 Credits exhausted` and never ran. We may describe this **exactly as written**, and it is a strength — see the thread copy in §2. |
| `#WorkBuddy` | **Zero usage.** Never installed, never invoked. Any sentence implying otherwise is a fabrication. |
| `#Miora` | **Zero assets in the build as of writing.** Every visual in the game is a procedural Phaser shape. We wrote `docs/MIORA_ASSET_BIBLE.md` (a style bible, prompt templates and a file contract), but **wrote a prompt document ≠ used the tool.** Do not blur that. |

### The resolution — three rules

**Rule 1 — Hashtags go in a labelled block, never inside a sentence.**
Put every tag on its own final line under an explicit label. A hashtag under
`Event tags:` is a submission-category marker, which is what the organiser is asking for. The same
hashtag inside `"built with #CodeBuddy and #Miora"` is a factual claim about your stack. Same
characters, completely different liability.

**Rule 2 — Ship the disclosure line in the same post, always.** Not a reply, not a comment, not a
pinned follow-up. Same post, visible without clicking "more". If a platform truncates it, shorten
the body — never the disclosure.

**Rule 3 — Never write these sentences.** Not in any variant, not "just for the caption":
- ~~"Built with CodeBuddy, WorkBuddy and Miora"~~
- ~~"Art generated by Miora"~~ / ~~"Miora-powered visuals"~~ / ~~"our Miora art direction"~~
- ~~"Powered by AI" over gameplay footage that contains no AI~~
- ~~"Tested with older residents"~~ / any participant count / any user number
- ~~anything with "improves memory", "prevents", "delays", "cognitive benefit", "dementia"~~
- ~~"Deployed on EdgeOne"~~ unless an `*.edgeone.app` URL is actually returning 200

### THE DISCLOSURE LINE — copy verbatim

**Primary (use this one, 176 chars):**

```
Tool note: the four tags are this hackathon's required event tags. Our actual AI use: CodeBuddy CLI for the initial codebase, then other AI coding agents. Full log in the repo.
```

**Short variant, when a platform is tight (108 chars):**


**Long variant, for LinkedIn / Rednote / YouTube description, where you have room to be maximally
clean (this is the strongest version — use it wherever it fits):**

```
Tool note: #CodeBuddy #WorkBuddy #Miora #TencentCloudHackathon are this hackathon's required
event tags, not a claim about our stack. What we actually used: CodeBuddy CLI 2.127.0 authored
the initial codebase (that run failed its checks; we caught it and fixed it), and other AI
coding agents did the rest under human direction. We did not use WorkBuddy. No Miora assets are
in this build — every visual is procedurally drawn. The full log, including the failures, is in
docs/AI_USAGE_LOG.md.
```

### Why volunteering "we did not use WorkBuddy or Miora" is the right move

It reads as confidence, not deficiency. Every other post today will say "built with CodeBuddy +
Miora ✨". Yours says *here is exactly what we used, here is what we didn't, here is the log
including the run that failed.* That is the single most credible thing a hackathon team can say,
and it is the same reframe the deck's AI slide runs on: **we treat AI output as a pull request,
not as a deliverable.**

### If the art sprint lands before you post

If Miora genuinely produces assets that ship in the build, swap in **§5, Variant M**. Do not
retro-edit an already-published post to add a Miora claim — post the update as a new reply/comment
with the asset visible. And if Miora produced *some* assets and Google AI Studio produced the rest,
say both tool names. Per-file attribution lives in `docs/AI_USAGE_LOG.md`.
