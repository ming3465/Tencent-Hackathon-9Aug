# Miora Exports

This directory is reserved for approved Miora-generated assets. The game
currently uses procedural Phaser art as a fallback.

Follow `docs/MIORA_ASSET_BIBLE.md` before adding exports. Keep original Miora
links and prompts in `docs/AI_USAGE_LOG.md`, use transparent PNG components,
and never commit unlicensed third-party source material.
