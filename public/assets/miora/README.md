# Miora Exports

This directory is reserved for approved Miora-generated assets. The game
currently uses procedural Phaser art, while generated visual references live
under `docs/art/`.

Follow `docs/MIORA_ASSET_BIBLE.md` before adding exports. Keep original Miora
links and prompts in `docs/AI_USAGE_LOG.md`, use transparent PNG components,
and never commit unlicensed third-party source material. Miora output may enter
the playable bundle after human review at actual game scale; do not claim a
Miora run until one has actually occurred.
